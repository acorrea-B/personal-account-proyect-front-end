# Instrucciones para agentes

## Trabajo de interfaz y experiencia de usuario

Antes de diseñar, implementar o revisar una pantalla, leer y aplicar
[design-professional-ui](.agents/skills/design-professional-ui/SKILL.md).
Si el modelo no descubre skills automáticamente, leer ese archivo y las referencias
que correspondan a la tarea de forma explícita.

Definir tarea, jerarquía, representación de datos, rol del color y estados antes
de implementar. Mantener contratos de API, validación, sesión, rutas e i18n en/es.
La dirección UI de 2026-11-01 del design brief permite extensiones semánticas
razonadas sobre Seline; no reducirla a copiar una paleta ni a colorear cada card.

Verificar visualmente los cambios de UI cuando haya navegador y declarar cualquier
limitación. Un encargo de documentación o skill no implica rediseñar o desplegar.
Para otras tareas, seguir las instrucciones y comprobaciones pertinentes del proyecto.
