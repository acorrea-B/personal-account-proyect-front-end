# Memory: UI Motion Atlas as a foundation source

The evaluated UI Motion Atlas skill provides a strong foundation for structuring views:

- choose one foundation scene before atomic animations
- make section jobs distinct
- keep composition, media and typography coherent
- treat motion as narrative support, not decoration
- reject repeated equal-card defaults with anti-slop checks
- require reduced-motion and responsive recomposition

It complements `docs/design-brief.md`, but does not replace project-specific visual criteria, content ownership, token consistency, contrast-by-surface rules, or implementation QA. The landing redesign used it as a structural criterion while keeping the project's Seline/Refero tokens and component system.
