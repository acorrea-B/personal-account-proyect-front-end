# Foundation scene registration for the initial view

- Foundation scene chosen: product demonstration stage (from UI Motion Atlas methodology)
- Purpose: lead with a clear account-access and proof layout while preserving the project's Seline/Refero token system
- Structural rules:
  - one dominant media field and one persistent action cluster
  - asymmetric proof, rails and action section rather than equal repeated cards
  - page transition smooth and opacity-only where possible
  - element-by-element sequence, not simultaneous flashes
  - mobile remains a distinct recomposition, not a scaled desktop
  - reduced-motion preserves all content and CTA visibility
- Established criteria preserved:
  - semantic auth flow and token security
  - Refero/Seline color token ownership
  - card text remains legible by surface
  - HTTP 200 / lint / typecheck / 34 tests / static export build gates
