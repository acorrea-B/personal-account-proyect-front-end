# Refero view mode preference

When browsing Refero (https://styles.refero.design), use the **extended** presentation, not compact. The extended view provides more surface, composition and spacing context for decision-making. Compact view is only a reference snapshot and should not be used for layout direction.

The extended Design Tokens (all 38 measured type steps, radii, spacing and
component recipes) are not in the page's static text: they live in the data
the page renders from. They are saved in
`design/references/selected-style.tokens.json`; read that file, not the
compact summary, when choosing tokens (operator rule, 2026-10-31).
